# 家人健康（牧羊人 · 健康页签）设计

2026-11-02 定稿的方向和取舍；阶段 1 已实现，后面几期按这里做。代码：`js/hl.js`（数据层）、`js/health-lib.js`（纯逻辑，有单测）、`js/data/health-ref.js`（化验项目 / 体征参考范围 / 就诊类型）、`js/health.js`（页面与表单）。数据库：baby-log 仓库 `supabase/migrations/026_shepherd_health.sql`。

## 1. 问题与成功标准

**问题**：体检、看病、化验结果散在各家医院的门户和纸上，看不出一个人的走势；医生说的「减重 5%」「少盐」「补维 D」没有变成每天的饮食、锻炼安排，也没人提醒复诊、该体检、该抽血。

**成功标准**

- 任何一位家人，30 秒内看到关键指标走势（体重 / BMI、血压、血脂、A1c / 血糖；孩子看身高体重）和最近一次就诊说了什么。
- 记一次就诊 ≤ 2 分钟（手填，或拍就诊小结 / 化验单让 AI 读出来、人工确认）。
- 复诊、年度体检、复查化验到期前进提醒（日历订阅）。
- 笔记本和手机都好用。

**和其他应用的关系**

- 小月亮：同一个 Supabase 项目。孩子列表读 `children` 表（没有就读 `families.settings.children`），身高体重读 `entries` 里 `type = 'baby'` 的记录（`data.weight` kg、`data.length` cm、`data.child`），只读。
- 爱家小助手：**是另一个 Supabase 项目**，不能跨库关联、也不共享行 id。联动只做网址跳转（带预填参数打开爱家的页面，例如记一张医疗账单、把模版食材加进采购清单），数据各存各的；爱家那边需要时再加对应的网址参数。

## 3. 信息架构

底部新增页签「健康」（`S.tab = "health"`）：

```
健康
├─ 家人切换（我 / 配偶 / 孩子…；手机横排可滑）
├─ 概览    关键指标卡（最新值 + 小走势线 + 偏高 / 偏低）· 走势图（可切指标，标出就诊日）· 待办 · 最近一次就诊
├─ 就诊    年度体检 / 普通门诊 / Urgent care / 急诊 / 专科 / 牙科 / 眼科 / 线上问诊；体征、诊断、医生建议、复诊日期
├─ 化验    按项目看历史，超出参考范围标出；可挂在某次就诊上
├─ 测量    在家量的体重、血压、心率、血糖、体温、腰围
└─ 档案    出生日期、性别、身高、过敏、既往病史、长期用药、目标
（阶段 2–4：训练 · 饮食 · 计划与推荐）
```

## 4. 数据模型（迁移 026）

- `subject`：大人 `u:<user id>`，孩子 `c:<children.id>`。
- 每张表都有 `family_id`（守卫触发器按记录人所在家庭自动填）和 `created_by`（不可改）。RLS：自己记的，或这行属于我所在家庭（active 成员）。
- `hl_profiles`（一人一行，`data` jsonb）、`hl_visits`（`vitals` jsonb：weight_kg / height_cm / sys / dia / hr / temp_c / spo2）、`hl_labs`（一项一行，`code` = 内置项目，`ref_low / ref_high`）、`hl_measures`（kind + value / value2，统一公制）。
- 数据量小（一家人一年几十次就诊、几百条化验和测量）：登录后整批读进内存（`readPaged`，不被 1000 行截断），在内存里算走势和待办；写入后更新内存并重画。

## 5. 单位

数据库统一公制（kg、cm、°C、mg/dL、mmHg）。显示单位跟着界面语言走：English = 美制（lb、in、°F），中文 = 公制；健康页「档案」里可以改，存本机（`shepherd.v1.units`）。血糖统一 mg/dL（mmol/L × 18）。

## 6. 待办规则（概览页、日历订阅）

- 复诊：就诊填了复诊日期且还没到 / 刚过 14 天内。
- 年度体检：上次 `annual` 距今 ≥ 11 个月（大人）；孩子的体检日程在小月亮，这里只提示去小月亮看。
- 复查化验：某项上次异常且距今 ≥ 3 个月；正常的血脂 / A1c 距今 ≥ 12 个月。
- 体征异常：最近一次血压 ≥ 130/80、BMI ≥ 25 或 < 18.5（大人），只提示「复诊时问医生」，不下结论。

## 7. 拍照读取（AI，用户同意过）

就诊 / 化验表单里「📷 从小结 / 化验单读取」：照片在浏览器里压缩后发给用户自己配置的 AI，要求返回 JSON（日期、类型、机构、体征、诊断、医生建议、复诊日期、化验项目数组）；只发图片，不发姓名；结果预填表单，用户核对后保存（`ai_used = true`）。照片不保存。

## 8. 阶段 2–4（2026-11-02 已实现，迁移 027）

代码：`js/data/health-plans.js`（内置 16 个训练、10 个饮食模版，中英文）、`js/health-plan-lib.js`（推荐、本周统计、AI 摘要 / 解析、爱家网址，`tests/health-plan-lib.test.mjs`）、`js/health-plan-ui.js`（计划 / 训练 / 饮食页、模版详情、自建模版、记录）。表：`hl_templates`（家里自建的模版，全家共用）、`hl_activity`（训练 / 饮食记录，只读近 400 天进内存）。每个人当前的计划存在 `hl_profiles.data.plan`（`workout: { tpl, name, days, time, remind }`、`diet: { tpl, since }`），AI 结果存在 `data.ai`。

- **训练（P2）**：模版库按大人 / 孩子分；模版详情列动作（组 × 次 / 秒 / 分钟）。「今天照做了」一下按模版分钟数记一次；也可以记自由训练、改分钟、写备注。给自己记的同时给「锻炼」习惯加一次打卡（`wb_logs`，记下 id，删训练时一起删）。「复制后改成自己的」：一行一个动作（「深蹲 3×12」「平板 3×30秒」「快走 20分钟」）。
- **饮食（P3）**：少记录优先——每餐点一下 ✓ 照做 / ◐ 部分 / ✕ 没照做，再点一次取消，不记热量；最近 7 天一张格子。孩子只有「餐盘法」，不显示热量、不出现减重。模版的「常买」一键带到爱家小助手：打开 `home-pantry/#/shopping?add=燕麦|糙米|…&from=模版名`，爱家那边列出来勾选确认后加进采购清单（不同数据库，只靠网址）。
- **计划与推荐（P4）**：规则层按最近的化验（LDL / 总胆固醇 / 甘油三酯 / HDL、A1c / 空腹血糖、维 D / 铁蛋白 / 血红蛋白）、最近的血压（≥ 130/80）、BMI（≥ 25 / < 18.5）、就诊的医生建议和诊断原文、档案的病史和目标里的字眼打标签，每个标签列出依据；按标签给模版打分（通用模版降权），各给前几名；65 岁以上不推高强度。可选「让咩咩咩分析」：去掉姓名的摘要（年龄、性别、体征、化验、病史、用药、目标、最近 3 次医生建议）发给用户自己的 AI，只能从内置模版 id 里选，返回摘要、建议、复诊时问医生的问题；结果要点「用」才变成计划。
- **提醒**：日历订阅加上训练计划（我自己的 + 孩子的，按星期几和时间点每周重复）；复诊照旧。网页推送没做：需要 PWA + Service Worker + VAPID 密钥 + 定时发送的 Edge Function，iPhone 还要先加到主屏幕；日历订阅已经覆盖提醒，需要时再加。
- 本周统计：成人目标每周 150 分钟（WHO / AHA），孩子每天 60 分钟；饮食照做率 = 照做 + 部分 × 0.5。

## 8.1 化验录入和显示（2026-11-02.3，按真实的 MyChart / Epic 结果页调整）

- 项目按化验单上的套餐分组：血脂 Lipid（总胆固醇、甘油三酯、HDL、LDL、VLDL、胆固醇 / HDL 比值、非 HDL）、代谢综合 CMP（血糖、BUN、肌酐、eGFR、钠、钾、氯、CO₂、钙、总蛋白、白蛋白、总胆红素、ALP、AST、ALT）、血常规 CBC（WBC、RBC、血红蛋白、压积、MCV、MCH、MCHC、血小板、RDW、MPV）、糖化、甲状腺、维生素与铁、其他。每项带化验单上常见的写法（alias：Calculated LDL、Direct HDL、Risk Factor、GFR CKD-EPI、Carbon Dioxide…），读图对项目用。
- 范围以化验单为准：「74–109」两边都有，「150 or below」「below 5.0」只有上限，「40 or above」只有下限；单子上没写才用默认的常见范围。同一个化验室的 LDL 上限可能是 130 而不是指南的 100，偏高 / 偏低按每一行存的范围判断。
- 录入一整份：选套餐，表里列出这一套的全部项目，填数字（单位、范围可改）；或者拍照 / 门户截图（一次最多 6 张，CMP 常常要 3 张）、粘贴结果页的文字，AI 把每一套都填进表，重叠的截图里同一项只留一次；「空腹」记在备注。可以挂到附近的一次就诊上。只存填了结果的项目。
- 概览：「关键指标」只放体征（体重、BMI、血压、心率，在家测的血糖）；化验另起「化验结果」，下拉框选套餐（默认「需要留意」= 偏高 / 偏低的；都正常时是最近一次的那一套），一行 = 名称 · 数值 · 范围条（绿段 = 参考范围，竖线 = 这次的值）· 和上次比。点一行看走势；只有一次结果时不画图，直接说「再记一次就能看到走势」。
- 化验页：按套餐分段，每段写有几项超出范围，每项最近 4 次可点开改。

## 8.2 手机上的健康页头部（2026-11-02.3）

宽屏照旧：新建按钮一排、家人芯片、内容芯片。手机（≤ 640px）：一行「家人下拉框（默认当前登录的人）+ ＋ 记一笔」，下面一个内容下拉框（概览 / 计划 / 训练 / 饮食 / 就诊 / 化验 / 测量 / 档案）。「＋ 记一笔」展开小菜单：就诊、化验、测量、训练。不用浮动的 + 按钮：会挡住底部页签和列表最后一行。

## 10. 风险与边界

- 只做记录和按公开指南提醒，不诊断；每条推荐写依据和「以医生意见为准」。
- 健康数据最敏感：RLS 按家庭隔离；照片不存；发给 AI 只在用户点了以后、且不带姓名。
- 孩子：不显示热量、不出现「减重」字样。
